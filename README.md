# Chzzk VOD Archiver

<img src="assets/chzzk_logo.png" width="200">

네이버 치지직 다시보기 링크 하나로 방송 아카이빙 전 과정을 자동으로 수행하는 macOS용 도구입니다.

## 파이프라인

`./archive.sh <링크>` 한 번으로 아래 네 단계가 순서대로 실행됩니다. 이미 처리된 단계는 자동으로 건너뛰므로 같은 링크를 다시 실행해도 안전합니다.

### 1. 타임스탬프 노트 기록
치지직 API에서 방송 날짜·제목·영상 ID를 조회해 옵시디언의 타임스탬프 노트 끝에 추가합니다. 노트에 이미 있는 영상 ID는 건너뜁니다.

### 2. 채팅 크롤링
채팅 API를 처음부터 끝까지 돌며 전체 채팅을 수집해 두 파일로 저장합니다.

- `all_chats.md` — 전체 채팅
- `filtered_chats.md` — 리액션성 채팅만 추린 필터본. 강조 유저는 닉네임에 밑줄 표시

각 줄은 `[시:분:초:프레임] 닉네임 (유저 ID) - 내용` 형식(60fps 기준)이라 편집 시 프레임 단위로 위치를 찾을 수 있습니다. 봇 계정과 프로필 없는 레코드는 제외합니다. 파일 맨 위에 영상 ID를 기록해 두고, 같은 날 다른 방송의 로그가 이미 있으면 파일명에 영상 ID를 붙여 덮어쓰기를 막습니다.

### 3. 프리미어 마커 XML 생성
필터 채팅의 밀도를 분석해 하이라이트 구간을 찾고, Premiere Pro용 시퀀스 XML로 저장합니다. Premiere에서 File > Import 하면 영상이 올라간 시퀀스와 하이라이트 마커가 한 번에 생성됩니다. 마커 이름은 `[채팅 수] 대표 채팅` 형식입니다. 검출 방식은 아래 [하이라이트 검출](#하이라이트-검출) 참고.

### 4. 영상 다운로드
yt-dlp로 최고 화질(1080p60)을 8개 동시 연결로 다운로드합니다. 표준 mp4로 저장되므로 별도 변환 없이 바로 Premiere에서 열 수 있습니다. 이미 받은 영상은 건너뛰고, 디스크 여유 공간이 30GB 미만이면 다운로드하지 않고 중단합니다. 영상 한 편(약 23GB) 기준 7~8분이 걸리며, 나머지 단계는 모두 합쳐 3초 이내입니다.

## 요구 사항

- macOS, Python 3 (기본 설치본으로 충분, 외부 패키지 불필요)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)와 ffmpeg: `brew install yt-dlp ffmpeg`

## 사용법

```
git clone https://github.com/zxc88kr/chzzk-vod-archiver.git
cd chzzk-vod-archiver
./archive.sh
다시보기 링크 또는 영상 ID를 입력하세요 (종료: q 또는 빈 입력): https://chzzk.naver.com/video/9330920
```

링크를 인자로 넘기면 바로 실행됩니다. 여러 개를 넘기면 연속 처리합니다.

```
./archive.sh https://chzzk.naver.com/video/9330920
```

채팅 크롤링만 필요하면 단독으로 실행할 수 있습니다.

```
python3 chat.py [링크]
```

## 결과물

| 위치 | 내용 |
|---|---|
| `videos/{MMDD 제목}.mp4` | 영상 (1080p60) |
| `premiere/{MMDD 제목}.xml` | 프리미어 마커 XML |
| `logs/{YYYY-MM-DD}/` | 채팅 로그 (`all_chats.md`, `filtered_chats.md`) |

## 설정 (config.json)

채팅 처리 기준은 프로젝트 루트의 `config.json`에서 관리합니다.

| 키 | 역할 |
|---|---|
| `highlight_users` | 닉네임에 밑줄을 표시할 유저 ID 목록 |
| `bot_users` | 로그에서 제외할 봇 계정 ID 목록 |
| `filter_messages` | 필터본에 남길 기준 문자 목록 (하나라도 포함된 채팅만 유지) |

유저 ID는 `all_chats.md`에서 닉네임 뒤 괄호 안의 해시를 복사하면 됩니다.

## 옵시디언(Obsidian) 연동

기본 볼트 위치(`~/Documents/Obsidian Vault`)가 존재하면 별도 설정 없이 함께 저장합니다.

- 채팅 로그 → `치지직/로그/{YYYY-MM-DD}/`
- 타임스탬프 노트 → `치지직/타임스탬프.md`

## 하이라이트 검출

필터 채팅을 20초 창으로 훑으며 리액션이 몰린 구간을 찾습니다.

- 기준: 방송 평균 밀도의 3배와 절대 최소 4건 중 높은 쪽 — 방송마다 자동 조정
- 채팅은 사건보다 늦게 터지므로 마커를 10초 앞당겨 배치
- 마커 간 최소 간격 80초, 최대 30개. 상한을 넘으면 경계 동점 후보를 방송 시간 전체에서 균등하게 선택
- 마커 이름의 대표 채팅은 리액션 문자를 제거한 뒤 정보량이 가장 많은 채팅으로 선택

값은 `archive.py` 상단 상수로 조절할 수 있습니다.
