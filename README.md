# Chzzk VOD Archiver

<img src="assets/chzzk_logo.png" width="200">

네이버 치지직 다시보기 링크 하나로 방송 아카이빙 전 과정을 자동으로 수행하는 macOS용 도구입니다.

1. **타임스탬프 노트 기록** — 방송 날짜·제목·영상 ID를 옵시디언 노트에 추가
2. **채팅 크롤링** — 전체/필터 채팅을 마크다운 로그로 저장
3. **프리미어 마커 XML 생성** — 채팅이 몰린 하이라이트 구간을 Premiere Pro용 시퀀스 XML로 저장
4. **영상 다운로드** — yt-dlp로 최고 화질(1080p60) 다운로드

이미 처리된 단계는 자동으로 건너뛰므로 같은 링크를 다시 실행해도 안전합니다.

## 요구 사항

- macOS, Python 3 (외부 패키지 불필요)
- yt-dlp와 ffmpeg: `brew install yt-dlp ffmpeg`
  (다시보기는 yt-dlp, 라이브 녹화는 ffmpeg를 직접 사용합니다)

## 사용법

```
./archive.sh
다시보기 링크 또는 영상 ID를 입력하세요 (종료: q 또는 빈 입력): https://chzzk.naver.com/video/9330920
```

링크를 인자로 넘기면 바로 실행되고, 여러 개를 넘기면 연속 처리합니다.

```
./archive.sh https://chzzk.naver.com/video/9330920
```

채팅 크롤링만 필요하면 `python3 chat.py [링크]`로 단독 실행할 수 있습니다.

구성은 `chat.py`(채팅 — 다시보기 크롤링과 라이브 실시간 수집)와 `archive.py`(아카이빙 — 다시보기 다운로드와 라이브 녹화) 두 파일입니다.

### 라이브 녹화 (`live.sh`)

다시보기가 올라오지 않는 방송에 대비한 보험입니다. 채널을 감시하다가 방송이 켜지면 영상과 실시간 채팅을 함께 받아두고, 방송이 끝나면 mp4로 변환한 뒤 마커 XML까지 만듭니다.

```
./live.sh
```

`config.json`의 `live_channel_id`를 쓰며, 라이브 주소를 인자로 넘기면 그 채널을 감시합니다. 한 방송만 받고 끝내려면 `--once`를 붙입니다.

```
./live.sh https://chzzk.naver.com/live/<채널ID> --once
```

한 번 켜두면 방송 감지부터 녹화·변환·마커 생성까지 알아서 하고, 끄기 전까지 다음 방송도 계속 받습니다. 실수로 두 번 켜면 잠금이 막아줍니다(두 프로세스가 같은 파일에 쓰면 녹화본이 깨집니다). 도는 동안에는 시스템 잠자기를 막아 자리를 비워도 방송을 놓치지 않습니다.

### 정해진 시각에 자동으로 켜기

터미널을 직접 여는 수고를 덜고 싶다면 등록해 두면 됩니다. 지정한 시각에 터미널 창이 떠서 감시가 시작되므로, 돌아가는 모습은 직접 켰을 때와 같습니다.

```
./live.sh schedule 20:15     # 매일 20:15에 자동 시작
./live.sh schedule --status  # 현재 설정 확인
./live.sh schedule --remove  # 해제
```

맥이 잠자기 중이면 예약 시각의 실행이 깨어날 때까지 미뤄집니다. 다만 일단 시작되면 도는 내내 잠자기를 막으므로, 한 번 켜진 뒤에는 이 문제가 없습니다.

**다시보기가 우선입니다.** 다음 날 다시보기가 올라왔다면 평소대로 `./archive.sh`를 실행하면 됩니다. 같은 방송의 라이브 녹화본이 있으면 알아서 갈아끼웁니다 — 채팅 로그와 타임스탬프 노트는 다시보기 것으로 바뀌고, 라이브가 만든 영상과 XML은 지워집니다. 손댈 것이 없습니다.

다시보기가 끝내 올라오지 않으면 녹화본이 그대로 정본이 됩니다.

같은 방송인지는 **방송 시작 시각**으로 판단합니다. 라이브의 `liveId`와 다시보기의 `videoNo`는 서로 다른 체계라 같은 방송이라도 번호가 다르기 때문입니다. 채팅 로그 앞머리에 이 정보가 남습니다.

```
---
video: 14989790
opened: 2026-09-01 20:31:17     방송 시작 시각 - 이 방송의 신원
source: vod                      live 이면 아직 다시보기가 안 올라온 방송
---
```

같은 날 방송을 두 번 했다면 시작 시각이 다르므로 서로 덮어쓰지 않고 파일명에 시각이 붙어 나뉩니다(`all_chats_2340.md`).

다시보기가 올라왔는지 확인하는 일 자체는 자동화되어 있지 않습니다. 직접 보고 `./archive.sh`를 실행하는 단계입니다.

**영상과 채팅은 항상 같은 소스에서 온 것끼리만 짝지어 씁니다** — 라이브 영상에 다시보기 채팅을 섞으면 기준 시각이 달라 타임라인이 어긋나기 때문입니다.

## 결과물

| 위치 | 내용 |
|---|---|
| `videos/{MMDD 제목}.mp4` | 영상 (1080p60) |
| `premiere/{MMDD 제목}.xml` | 프리미어 마커 XML — Premiere에서 File > Import 하면 시퀀스와 마커가 생성됨 |
| `logs/{YYYY-MM-DD}/` | 채팅 로그 (`all_chats.md`, `filtered_chats.md`) |

옵시디언 볼트(기본값 `~/Documents/Obsidian Vault`, `config.json`에서 변경 가능)가 있으면 채팅 로그는 `치지직/로그/{YYYY-MM-DD}/`, 타임스탬프 노트는 `치지직/타임스탬프.md`에도 함께 저장됩니다.

## 설정 (config.json)

| 키 | 역할 |
|---|---|
| `highlight_users` | 닉네임에 밑줄을 표시할 유저 ID 목록 |
| `bot_users` | 로그에서 제외할 봇 계정 ID 목록 |
| `filter_messages` | 필터본에 남길 기준 문자 목록 |
| `live_channel_id` | `live.sh`가 감시할 채널 ID (라이브 주소 끝의 32자리 해시) |
| `obsidian_vault` | 옵시디언 볼트 경로. 비워두면 `~/Documents/Obsidian Vault`를 씁니다 |

유저 ID는 `all_chats.md`의 닉네임 뒤 괄호 안 해시를 복사하면 됩니다. 처음 사용한다면 `highlight_users`를 본인 계정 ID로 바꿔주세요.

## 하이라이트 검출

필터 채팅을 20초 창으로 훑어 리액션이 몰린 구간을 찾고, 채팅이 몰리기 시작한 지점에 마커를 찍습니다. 기준은 방송 평균 밀도의 3배(최소 4건)로 방송마다 자동 조정되며, 마커 간 최소 간격 80초에 최대 50개까지 생성됩니다. 값은 `archive.py` 상단 상수로 조절합니다.

## 라이브 녹화 동작 방식

- **감시** — 폴링 전용 API(`live-status`, 응답 약 1.7KB)를 30초마다 확인합니다. 하루 약 2.5MB로 상시 감시해도 부담이 없습니다.
- **앞부분 확보** — 감지에 최대 30초가 걸리지만, HLS 플레이리스트에 남아있는 앞부분(약 28초)까지 함께 받아 그 공백을 메웁니다(`-live_start_index 0`). 방송이 이미 진행 중일 때 켜도 마찬가지로 28초를 더 받습니다.
- **화질** — 최고 트랙(1080p60, 영상 8192kbps + 오디오 192kbps)을 재인코딩 없이 그대로 받습니다. 다시보기는 치지직이 8003kbps + 128kbps로 재인코딩하므로 라이브 쪽이 원본에 더 가깝습니다.
- **광고** — 치지직 광고는 웹 플레이어가 붙이는 방식이라 스트림에 섞이지 않습니다. 받은 파일에는 본편만 들어 있습니다.
- **저장 형식** — 녹화 중에는 `.ts`로 받고 방송이 끝나면 mp4로 변환합니다. mp4는 재생 인덱스를 파일 끝에 마지막으로 쓰기 때문에, 정전이나 강제 종료로 중단되면 그때까지 받은 분량이 통째로 열리지 않습니다. `.ts`는 어디서 잘려도 그 시점까지 재생됩니다.
- **잠자기 방지** — 프로그램이 도는 동안 `caffeinate`로 시스템 잠자기를 막고 끝나면 자동으로 풉니다. 방송을 기다리는 감시 구간에도 걸립니다 — 맥이 잠들면 폴링이 멈춰 방송이 켜져도 알아채지 못하기 때문입니다. 화면은 꺼지도록 두었습니다(`-d` 미사용). 다만 노트북 뚜껑을 닫으면 `caffeinate`로도 막을 수 없으니 뚜껑은 열어두어야 합니다.
- **중단 대비** — 스트림이 끊기면 재접속하고, 채팅 서버가 끊겨도 다시 붙습니다. 시작 시 여유 공간이 30GB 미만이면 녹화하지 않고, 녹화 도중 5GB 아래로 내려가면 스스로 멈춰 그때까지 받은 분량을 살립니다.
- **채팅 타임라인** — 실시간 채팅은 절대 시각으로 모았다가, 녹화가 끝난 뒤 `(종료 시각 − 실제 녹화 길이)`를 기준점으로 삼아 영상 기준 시각으로 변환합니다. 재생 버퍼 때문에 시작 시각을 그대로 쓰면 몇 초씩 어긋나는데, 끝에서 되짚으면 그 오차가 사라집니다.
- **성인·구독자 전용 방송** — 비로그인으로는 재생 정보가 내려오지 않아 받을 수 없습니다. 조용히 실패하지 않고 사유를 알린 뒤 건너뜁니다.

용량은 시간당 약 3.8GB입니다. 4시간 방송이면 약 15GB, 7시간이면 약 27GB입니다.
